# MAX_BOT — уточнённая классификация релевантности

Цель: находить сообщения о фактических проблемах телеком-инфраструктуры на территории РФ и показывать конкретные непосредственные угрозы отдельно. Ключевые слова — только вспомогательные признаки; одного совпадения слов недостаточно.

## Правила

1. **Подтверждённый инцидент.** Требуется явное описание воздействия на связь/интернет (например, «перебои с мобильной связью», «нет интернета», «связь не работает») либо подтверждённого физического повреждения телеком-инфраструктуры (например, повреждение ЦОД, кабеля, узла связи, здания телефонной компании). Событие должно быть связано с территорией РФ.
2. **Непосредственная угроза.** Конкретная потенциальная проблема в РФ получает `severity="warning"`, метку `угроза`, и `sendable=False`. Это не подтверждённая авария и не отправляется как аварийное уведомление.
3. **География.** Российское место должно находиться в том же контексте, что и событие. Случайное упоминание России в другом месте текста (например, «звонки в Россию» в статье о роуминге) не доказывает, что событие случилось в РФ.
4. **Отключение электричества.** Само по себе нерелевантно. Нужно явное указание перебоев связи/интернета или реального повреждения телеком-инфраструктуры.
5. **Общие новости / статистика / жалобы.** Обсуждение законопроекта, корпоративные успехи, статистика DDoS, общие упоминания проблем и жалоб не считаются инцидентом без конкретного актуального воздействия. Узкое исключение: сообщение о повторяющихся/продолжающихся сбоях конкретного российского провайдера.
6. **Восстановление.** Сообщение о восстановлении учитывается как `normal` только при явном контексте предшествовавшей аварии/сбоя и российской географии.
