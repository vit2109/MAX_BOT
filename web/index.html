Настройки

В «Отфильтрованные новости»

Текст попадает слева только если есть слово из группы 1 (тематика: оператор, IX, технология) и хотя бы одно слово из группы 2, 3 или 5 (проблема / статус / восстановление). Топоним сам по себе не означает аварию. Подтверждённое восстановление снижает важность, если нет признаков продолжающейся проблемы. Поле «минимум совпавших слов» — дополнительный порог.

В отправленные адресатам

Уходит в чат только уже отфильтрованное сообщение, если включено «Отправлять совпадения» и список адресатов не пуст. При первом запуске загружаются до 100 последних постов без рассылки. Новые события и посты API обрабатываются далее. Перепроверка архива не запускает рассылку. Неудачные отправки повторяются из очереди. «Слать только критические» — в чат только красные (аварийный сигнал).

Пример

«На MSK-IX проблемы, авария на подстанции» → группа 1: MSK-IX, группа 2: авария/проблем → в отфильтрованные, важность критическое. Без слова из группы 1 новость останется только справа, во всех новостях.
